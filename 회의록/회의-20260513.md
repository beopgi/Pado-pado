## 논의 및 구현 내용
**주요 안건 :** 핵심 UI 구현 현황 점검 및 공모전 전략 논의


- 로그인 시스템  
    단순 이메일 로그인 외에 SSO(Social Single Sign-On) 도입  
    구글(Google) 및 카카오(Kakao) 로그인** 연동 완료  
    Clerk와 연동하여 사용자 인증 토큰 관리 확인  

- 홈 화면(Home) : 앱의 메인 대시보드 레이아웃 구현  
- 날씨 정보 및 AI 추천 영역 섹션 배치 완료  
- 지도 화면(Map) : 구글 맵 API 기반의 기본 지도 인터페이스 구현  
- 기존에 논의된 마커 팝업을 띄우기 위한 베이스 작업 완료  
- 공모전  
    해양수산부 및 공공기관 지원을 겨냥하여 '해양 안전 교육 이수' 로직과 '실시간 세일링 트래킹' 기술력을 강조  


## 결정 사항
- 인증 방식 : 사용자 편의성을 위해 소셜 로그인(SSO)을 기본으로 하되, 보안을 위해 JWT 검증 과정을 백엔드와 최종 동기화함
