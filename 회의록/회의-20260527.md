## 논의 내용
- BM(비즈니스 모델) 사업화 전략
    - 중개 수수료 : 요트 및 해양 레저 예약 매칭 시 발생하는 기본 중개 수수료 기반의 안정적 수익 구조 확립.
    - 개인 맞춤형 구독 모델 : 실시간 세일링 데이터 분석을 통해 '인기 항해 경로 데이터' 및 맞춤형 해양 정보를 제공하는 프리미엄 구독 서비스 구상.
    - 상점 탭 및 제휴 노출 : 앱 내 상점(Store) 탭을 신설하여 해양 레저 용품 및 연계 관광 상품을 판매하고, 인근 업체 프리미엄 제휴 노출을 통해 광고 수익화 확장.

- Flutter 클라이언트 구현 및 수정
    - 결제 화면 UI 개선 : 기존의 팝업(Popup) 형태의 결제 코드 입력 디자인을 흐름의 끊김이 없는 페이지 기반(Page-based) 디자인으로 수정하여 결제 편의성 향상

- 일반 사용자 앱 화면뿐만 아니라, 생산자가 활용할 수 있는 운영자 대시보드 장표를 추가하여 B2B 확장성 증명.
- 구체화된 4대 수익 모델(수수료, 구독, 상점, 제휴 광고) 중심의 사업화 전략으로 슬라이드 보강.
- QR 코드 기반 상호작용 및 실시간 검증 : 사용자와 사업자 간의 유기적인 연동을 위해 QR 코드 시스템을 구축  - 선박 실시간 인원 확인 콜백(Callback) 기능 : 사용자가 선박 탑승 시 QR 코드를 스캔하면, 백엔드에서 실시간 승선 인원을 카운트하여 현재 선박에 몇 명이 탑승해 있는지 등을 즉각 띄워주는 실시간 콜백 로직을 추가하기로 확정
