# 제 6회 팀 내부 정규 미팅 회의록

## 개요
- 일시 : 2026.05.06 (수) 18:00
- 장소 : 공과대학 내 카페
- 참석자 : 김법기, 김은수, 이지현, 임라라, 정소영
- 회의록 작성자 : 정소영


## 논의 내용

- 프론트엔드  
    Figma 디자인의 Flutter 전환(현재 약 90%) 및 UI 에셋 최적화 작업 진행 중  
- 백엔드/DB  
    Firebase 기반 DB 설계 및 Clerk를 이용한 JWT 로그인 검증 로직 검토  
- 서버 운영  
    현재 로컬 서버로 테스트 중이며, 향후 AWS(Amazon Web Services)로의 이전 및 운영 방안 논의  

- 지도 및 트래킹  
    구글 맵 API 연동. 데이터 크롤링 대신 DB에 좌표(XY), 이미지, 링크를 직접 저장하는 하드코딩 방식으로 관리 효율성 및 결제 연동성 확보  
- 기능 간소화  
  게시물 임시 저장 기능은 우선순위에서 제외(안 하는 것으로 결정)하고, 핵심 기능인 트래킹과 예약에 집중  
- 공공기관 지원 전략  
  해수부(해양수산부) 등 공공기관 어필을 위해 '안전 교육 확인제'를 도입할 예정 승선 전 필수 영상을 시청(3개 체크)해야 확인증이 발급되는 로직으로 추후에 진행  


## 결정 사항

- 지도 구현  
    구글 맵 API를 연결하고, 행사용으로 마커 하나를 수동 등록하여 시연용 MVP를 구축  
- 예약 및 결제  
  마커 클릭 시 팝업을 통해 상세 정보(이미지, 링크 등)를 보여주고, 예매하기 버튼을 통해 결제로 이어지는 흐름  
- 리뷰 시스템   
  항해 종료 후 자동으로 리뷰 작성 창(사진 첨부 포함)이 뜨도록 설계하여 데이터 축적을 유도  
- 일정   
  5월 말 해수부 지원서 작성을 위해 시각적 자료(그림 등) 준비해서, 6월 초 전체 마무리를 목표  
- 안전 시스템  
  3개의 안전 영상을 모두 시청해야 탑승 확인증이 나오는 시스템을 구현할 예정 (추후)  


## 향후 할 일 (Action Items)

 **김법기** : 지도 API 수정 및 마커 팝업 구현, 날씨 API 연동  
 **김은수** : DB 설계 및 데이터 인서트(이미지, 링크, 좌표), JWT 로그인 검증 마무리, 백엔드 기록 로직 구축  
 **이지현** : 지도 마커 팝업 및 앱 내 UI 디자인 에셋 적용, 라라 씨와 UI 정보 업데이트 협업  
 **임라라** : 플러터 프론트엔드 UI 최종본 공유, 로그인 기능 연동, 지현 씨와 UI 에셋 덮어쓰기 작업  
 **정소영** : AWS 서버 구축 및 운영 관리, 주간 활동일지 및 회의록 업로드
