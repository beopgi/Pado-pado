    - 로그인, 홈 화면, 마이페이지 위주로 우선 완성.  
    - 홈 화면에 AI 추천 섹션 배치를 위한 레이아웃 최적화.  
    - 프로필 사진: 가입 초기에는 기본 아이콘으로 설정하고, 마이페이지에서 변경할 수 있도록 수정.  
    - 결제 UI: 결제 페이지에 리딤 코드 입력란을 배치하여, 코드 입력 시 0원이 되도록 설정(해커톤 시연용).  

- AI 모델 (MCP 논문 기반)  
    - 초기 사용자 데이터 부재 시 위치 정보 기반 추천 우선 수행.  
    - 사용자 활동(낚시, 요트, 서핑 등) 태그가 쌓임에 따라 맞춤형 추천으로 업데이트.  

- DB 아키텍처 및 스토리지  
    - Firebase에서 이미지 미출력 방지를 위해 Firebase Storage 활용 및 대소문자 구분 철저히 관리.  
    - Clerk를 사용해 프론트엔드 단에서 로그인을 구현하고 JWT 토큰으로 검증.  

- 결제 프로세스  
    실제 결제 기능을 구현하되, 해커톤 현장 배포를 위해 리딤 코드** 입력 시 0원 결제가 가능하도록 팝업 또는 입력 칸 추가.
